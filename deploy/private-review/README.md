# 私有手机入口：待授权的独立主机配置包

这些文件仅为配置样例，未安装、未部署、未启动VPN或公开隧道。不能将它们当作已经获得授权的入口。

推荐：你控制的独立非生产Linux主机 + Tailnet内HTTPS（Tailscale Serve，**不使用Funnel**）+ 应用个人审核账号。iPhone/iPad使用Tailscale App加入你自己的Tailnet，Safari打开获批准的HTTPS地址，登录审核账号。数据库与8091只监听主机回环地址，只有Tailnet中的获准账号/设备可以到HTTPS443。

## 激活前必须确定

- 主机/区域/所有者/受控部署方式。只用明确批准的现有资源，不自动购买或订阅。
- 是否授权将当前私有非生产快照复制到该主机的加密磁盘；独立空数据库的名称、恢复权限、保留/销毁政策。与Railway production和生产Postgres不共享连接、密钥、卷或网络。
- Tailnet所有者账号与初始获准iPhone/iPad设备，设备审批、MFA和有效ACL。Tailscale处理账号/设备/连接元数据；WireGuard/HTTPS保护传输，中继不应取得明文。主机和手机端仍保存敏感数据。
- 只开Tailnet HTTPS443；不开放公网网站、8091、5432或Funnel。建议授权窗口7天，填入明确的UTC截止时刻，应用到期拒绝访问。应用会话8小时，可撤销；无需创建公开下载链接。
- HTTPS证书、准确origin、Secure/HttpOnly/SameSite cookie、逐人账号以及独立备份路径。证书透明日志可能显示通用主机名，避免含个人姓名或资料名。
- 谁负责续期、撤销设备、取回备份、主机维护与费用。任何额外第三方存储另行授权；不自动上传iCloud、Drive或GitHub。

## 获得上述明确授权后，由受控主机操作员执行

1. 安装Python3.12/PostgreSQL17及与该提交匹配的代码；创建独立服务用户和私有0600配置，使用SCRAM数据库密码。不要使用Codex本地trust认证配置。
2. 仅在获授权的空白非生产数据库恢复快照；不使用--clean/--create覆盖原库。核对迁移、六份来源SHA、所有持久表行数/摘要、38个有效题稿及45份版本。恢复后重新登记登录，会话数据不进入备份。
3. 备份若仅有001—015迁移，应在明确授权的恢复目标中应用016增量迁移，不重新导入教材/候选。预览、已签署事件、草稿意见必须分别核对。
4. 以review.service.example为基础准备服务；EnvironmentFile和备份目录只授权服务用户。示例网络限制只允许回环数据库和本机代理，不连接任何production服务。
5. 在**指定独立主机**配置Tailnet并审批设备，合并而非覆盖tailnet-policy片段。须检查现有所有ACL/grants中不存在更广的允许规则；仅添加本片段不能收窄已有全通规则。
6. 在授权主机启用Tailnet HTTPS Serve，目标为http://127.0.0.1:8091；不要运行tailscale funnel。当前Codex环境只有出站代理，不在执行器内安装或改配Tailscale来试图获得入站。
7. 从获准手机实测证书、登录、匿名数据拒绝、非获准账号/设备拒绝、过期访问拒绝、退出撤销、跨设备意见恢复、备份下载/Range续传/SHA。未验收前不声称iOS可用。

## 数据库最小权限

服务账号可SELECT该隔离schema所需表/序列；仅INSERT候选人工决定、未签署意见版本、会话、位置，并仅UPDATE会话撤销和位置。不给发布、修改题稿、修改教材或删除历史权限。备份需要读取该schema和序列，但排除reviewer_sessions数据。来源/科学/映射/发布操作仍由另一受控操作角色承担。

本轮未获得任何目标主机/部署凭据，未执行以上激活步骤。配置样例中的REPLACE/SET占位符故意不能直接运行。
