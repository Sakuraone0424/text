# 可选PDF工具（不属于当前六文件流程）

本项目的正式知识入口是 [六文件OCR-only流程](private-source-intake.md)，不请求用户提供PDF，不以原件PDF字节、哈希或物理页作为TXT/DOCX入库和证据的强制前提。旧OCR文件ID和PDF资料不再是当前有效资料。

保留此前有界工具仅供独立兼容测试/其他明确授权的用途：单原件100MiB；分卷每卷100MiB、总512MiB、最多16卷，单卷最多2000页/全书4000页；保存分卷SHA、真实页数、偏移和映射，拒绝重叠/越界/损坏。显式传入--original或--original-parts时进入可选PDF工具，也可指定--mode pdf-tools，仍要求隔离开发目标和私有报告。

这些能力不自动扩展本项目资料白名单；工具不能使用当前六文件ID冒充PDF来源，目录外工具数据不能用于当前训练发布或考频。历史PDF数据和旧成绩保留，不通过删除或降级迁移来“清理”。原010迁移不改写，011只为OCR-only新增结构并允许PDF页为空。
