## 人民币账本实现

- 新增 CNY 价格、预留、不可变费用事件、价格冲突确认和模型设置事件。原 daily_usd/monthly_usd、reserved_usd/actual_usd、旧预留和原任务快照归档保留，不套汇率、不重命名币种、不混入 CNY 累计；旧货币任务必须明确重排，不能偷偷继续扣款。旧预算激活状态迁移后暂停。
- 全部计算使用 Decimal/PostgreSQL NUMERIC，API 与手机端用十进制**字符串**传输金额，避免 FastAPI 默认把原始 Decimal 转为浮点。预算覆盖单任务（含重试）、首次试验累计、北京时间自然日及月；首次试验限额可明确关闭，此后其他限额仍保留。
- 每次尝试使用当前已核查的 CNY 价格单独预留；模型/思考档位仍冻结，原任务和历史价格不改写。用户级 PG 事务锁、行锁/租约及唯一幂等键防止并发竞争与重复预留。同一已存在任务不会因网络重发产生新调用；真正重试另建尝试并再次计预算。
- 超时、进程中断、取消或 usage 缺失保留全部预留。当前保守策略是**所有尝试预留均保留计入预算**，成功后的未用差额也不自动释放；因此额度可能早于估算费用用尽。避免将未知费用伪装为零。API 402 等非重试故障阻断，不无限重试；usage 超出预留上界触发停止开关。
- 服务端实际 usage 分缓存命中、未命中/缓存创建及输出；不估算 Token 冒充实测。已知短请求完整处于同一时段时按该时段估算；跨边界、年度日历未知或跨度异常时按峰值上界。usage估算、预留、未知待对账、带账单凭据的人工财务对账事件分开；财务对账不等于要求人工审题。
- /v2/model/billing 返回预算、估算、未知预留、调用尝试、已确认到达服务商的请求数、按任务统计及设置历史；/billing/history 支持任务过滤、游标及最多100条分页，只返回当前用户。没有 Key/密码/原题正文。Railway 外币账单不进入该账本。
- /model 页面增加人民币费用、任务/试验预算、停止开关、价格刷新和版本历史；修正原模型页不存在的 CSS 地址，并提供 44px 点击区、换行和手机适配。账号认证、Origin 校验与 no-store 保留。
