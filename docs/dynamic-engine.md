# 动态命题引擎与可重放边界

当前数据源以 [六文件OCR-only流程](private-source-intake.md) 和 [版本规则](data-versions.md) 为准。历史PDF交接要求已退出；经审核的OCR教材允许提供正式题目证据，DOCX转录不会自动进入原卷可信考频。算法版本与配额不变。

## 固定规则和优先级

版本 `knowledge-priority/1.0`。仅支持用户自定义的28题、150分、实际开始后60分钟；每科固定3/3/4/3/1题、2/3/4/8/20分。不是官方考试固定结构，也不是预测考试概率。动态计算只改变合格候选在固定槽位内被选中的相对权重，不能更改配额、分值或教材证据门禁。

先检查发布状态、完整Question结构、教材原件/正文/页码证据和已核验同科同型真题风格来源，再计算知识点优先级。失效题不进入计算候选宇宙。题库不足按学科/题型返回409及缺口，不生成半卷，不复用不合格旧题凑数。本人已见题干原则上排除，真实FSRS到期原题允许明确标记的复测；知识点变式同样明确标记。

## 来源范围与统计

操作员凭独立审核密钥，通过以下接口登记：

1. 导入并核验教材、原卷的私有source unit；关联实际知识标签。
2. `POST /v2/exams/scopes` 注册科目、paper_code、syllabus及证据，区分可比较范围。默认两科scope均为null，不自动混用其他考试。
3. `POST /v2/exams` 保存原题及来源，随后 `POST /v2/exams/{id}/classification` 追加真实原卷/模拟/转录分类、scope、知识映射、主次标签、贡献和认知层次。只有核验的real_exam、适用范围、实际原件和教材标签映射才进入考频。单纯导入不等于可信。
4. `POST /v2/exams/samples` 登记有原件和完整映射的年度样本。规范化去重数量必须与expected_questions一致；冲突映射必须先解决。未登记完整年份不能提供“没有考过”的负样本。
5. `POST /v2/selection/policies` 保存新配置并分配给用户；`GET /v2/selection/policies` 查看配置。所有版本/分配为追加记录，拒绝无效权重和未知字段。

同scope、同学科、同年规范化原题只计一次，跨年保留独立出现。同题不同转录映射冲突则排除，不挑有利版本。默认身份保留科学大小写、符号、上下标及词间分隔，仅NFC与空白归一；人工canonical_item_id用于审查后归并，不能自动证明语义等价。

一题的多标签贡献总和为1：显式正贡献归一，否则主标签权重2、次标签1。考频综合衰减贡献、平滑后的已知年份出现率和有界近期变化；未知年份不充作零。年度量、完整映射比例决定置信度，信号进一步向中性收缩，防止单年大量题目冒充多年证据。记录原题ID、年份、来源单元、分类版本、去重数、有效完整年份和置信区间；区间只针对实际可用样本，不代表未来真题概率。

## 学习与复习信号

已实际作答且完成批改的每道题是一份观测，以points/max_points衡量损失；20分论述题仍是一份观测。未答、待批和as_of之后的成绩不进入掌握度。多标签分摊观测质量，评分细则有知识标签时按评分点归属使用缺失分。主观题默认可靠性0.65，时间半衰期30天，先验有效量4；小样本向中性收缩。近期真实复盘的重复错误分类有有界调整，缺失分类不猜测。

真实FSRS-6记录用于到期、临近到期、稳定性、难度及复习时间。到期need=1；未到期按距到期时间连续衰减，24小时内另标near_due。选择过程只读，不更新记忆状态；空白、待批、正确题不写失败事件。旧1/3/7记录只读保留，不冒称FSRS。知识依赖只接受审核教材支撑的无环关系，提供有界前置知识调整。

旧60题答案缺乏可信知识点映射时，仅保留档案并报告unmapped数量，不猜测标签或混入掌握度。目前没有完成真实旧答卷的人工知识映射及历史回测。V2无细标签时明确使用已核验教材章节作为粗粒度回退，不能称细知识点精度。

## 权重、阶段与抽样

初始参考权重exam/weakness/review为0.55/0.30/0.15，实际各知识点权重乘本来源置信度后归一；全部缺失则中性探索。仅有考频时还保留其信号置信度收缩，避免归一为100%掩盖少样本。实际作答增多时平滑提高个人薄弱信号，非固定重点章节。

每科独立判断阶段：默认少于10份已批实际作答为冷启动；累计期随后；至少100份且平均缺口低于0.3为稳定期；距离显式目标日期0—45天、至少10份作答且有至少3年核验真题才进入考前期。目标日期默认2026-12-19，可配置，不能推断为官方考试日期。日期按Asia/Shanghai计算，一科数据不能替另一科触发阶段。

知识优先级还考虑真实高频与实际薄弱协同、经核验前置关系和近14天覆盖。默认exploration=0.08是正权重下限，不是硬性8%题数。题型和核心/机制/应用层次仅在足够真实样本时给有界调整，不使用70/20/10。章节使用软惩罚，不能以覆盖为由突破证据或固定配额。

固定学科/题型顺序、排序后的候选、本地带seed随机源执行加权不放回抽样。每个draw保存可用ID、最终权重及选中原因。相同记录上下文、算法、策略和seed可复现选择；不同用户知识状态在多seed统计测试中呈预期差异。统计测试为合成受控数据，不是对真实考研成绩提升的验证。

## 审计、权限与恢复

009迁移新增selection_policies、追加分配、不可变selection_runs等对象；001—008不变。每卷原子写入seed、algorithm_version、policy_id、as_of、配置、全部上下文、候选纳入/排除及逐次决策。未来的批改、复盘、FSRS事件和策略均按可用时间截断；历史FSRS使用截止前事件重建。重放以保存的上下文/候选为准，不能用今天题库替代过去，也不伪造旧卷缺失的轨迹。

审核员可访问 `GET /v2/selection/runs/{paper_id}`；学习者提交后才可访问自己的 `GET /v2/papers/{id}/analysis`，提交前不泄露seed、答案或选题轨迹。结果界面展示真实年份、样本、错误和复习依据、缺资料提示。历史无轨迹则明确historical_trace_not_recorded。

修改算法语义须增加版本并保留原版本重放说明；既有日志不更新。故障时暂停新生成、保留在途卷完成；不回退到旧60题服务、不回滚成绩或删除009。操作步骤见 [reviewed-quiz.md](reviewed-quiz.md)。

## 当前可验证范围

本地与CI覆盖合成来源、样本冲突、置信度、时间截断、阶段、正权重探索、600个seed的多场景抽样、实际下一张试卷受已批成绩影响、权限及不可变审计。四本真实教材、真实逐年原卷、旧档案人工映射和真实学习效果未获验证；Notion、受保护ChatGPT应用及AI识别/批改亦未因本引擎而获得授权或接通。配置能力不能算外部接入完成。

归档载荷还包含真实试卷日期、选题依据、学科成绩及知识点掌握估计的前后对照。前值来自组卷时不可变上下文，后值来自归档时实际已批作答；保留两侧时间、算法和策略配置。变化可能包含期间其他训练、时间衰减或策略变化，不能称本卷造成的掌握提升；未答/待批不增加样本，无原轨迹明确缺失。该载荷经模拟Notion读回验证，真实同步未启用。
