# 唯一现行训练规格

本文件明确当前产品要求；旧60题记录及历史需求仅供审计，不是另一种可用训练模式或恢复依据。需求说明、界面、自动备卷、适配器、AI出题和测试均遵循同一28题结构。

全卷28题、150分、60分钟（3600秒），生物化学和细胞生物学各14题、75分。计时从用户实际开始作答起算。

|每科题型|题数|每题分值|小计|
|---|---:|---:|---:|
|单选|3|2|6|
|填空|3|3|9|
|名词解释|4|4|16|
|简答|3|8|24|
|论述|1|20|20|
|每科合计|14||75|

`backend/app/training_spec.py`是代码规格来源。`GET /v2/training-specification`提供唯一当前规格，网页准备试卷从该接口取得配额；定时备卷和ChatGPT适配器使用同一默认蓝图。`Blueprint`及组卷后校验拒绝改题量、改分科配额、改分值或改时长。AI补题按相同COUNTS/POINTS确定缺口；科学/答案审核保持各自独立，不改变既有冻结材料。

每日定时准备指准备一套上述28题卷，不是每日60题训练。没有双模式选择、60题配置或60题生成入口。旧生成/提交接口继续退役，旧答卷与成绩只读展示，不能混入当前组卷池。旧数据库迁移、题目和成绩不改写。

本次产品规格纠正不部署Railway、不修改生产数据库、不合并main、不启动Worker或模型调用；3题DeepSeek限定试验的scope、payload、账本和门禁保持原样。
