# 正式审核门禁核查与本轮实录（2026-10-28）

本轮没有DeepSeek调用、人工签署、Worker、Railway变更或生产库访问。不是把一次Codex分析改名为多轮。

## 实际门禁要求

`auto_quality.schedule_checks`先执行identity预检，再安排**两个独立任务**：science_review和answer_review。生成题目不是额外审核轮次；程序身份检查也不能算独立AI审核。

- 科学轮不含候选的标准答案、rubric或Codex分析；使用题干/选项和重新读取的来源。单选必须独立给出正确选项。
- 答案轮取得完整候选、rubric及真实来源，但不继承科学轮结论。每个评分点须有原文支持；标签映射、OCR风险和五维检查均须解释。
- 两轮都要求succeeded、real_api=true、对应内容/证据版本一致、无未解决项。计算题还要确定性计算记录。
- 最终由程序检查两轮、identity、引文、评分、版本、重复等门禁并promote；没有额外真人最终批准要求。candidate_human_decisions不替代两轮，不应伪造人类签署。
- 本轮加固：只接受与数据库持久化任务一致的结果；任务kind必须与phase一致；ready要求科学与答案使用两个不同job ID且任务状态、内容SHA和来源快照仍匹配。测试中的合成结果不是真实模型验收。
- real_api字段本身不是服务商密码学认证；真实运行验收还必须核对受控Worker的调用、usage和费用记录，不能手写数据库字段来通过门禁。

## 最小独立审核方案与条件费用

不强制用户逐题人工审核。获得明确授权后先做不含私有资料的模型/思考档兼容性测试，再最多3题小样本：每题科学与答案独立新会话，共6调用；无冲突后才处理其余题。

价格尚未真实核验，不能给出官方实际费用。本页仅用用户提供的历史参考高峰价（输入未缓存2元/百万、输出8元/百万）演示预算：若输出上限2048 Token，现有程序每次按32,000输入上界预留，则单次预留0.080384元，3题两轮约0.482304元，38题两轮76次约6.109184元。必须先核验当期模型独立CNY价格才可采用；不是账单，也不是付费授权。未知价格必须阻断。

这是无重试、无修订、无兼容性调用的条件预留。一次全部重试将翻倍超过10元；若每题最多2次修订且每次完整重审，最多304个生成修订/审核调用，按同一上限示例约24.44元，不能用6.11元宣称覆盖修订全过程。先设置单任务/试验/日/月预算和输出/重试上限，未知费用保留预留；余额不足停止。不要一次开启全库处理。
