## 实际验证

环境：Python 3.12.14、PostgreSQL 17.11、pytest 8.4.2、Playwright + 本机 Chromium。

```sh
cd /workspace/text/backend
TEST_DATABASE_URL=postgresql://agent@127.0.0.1:5432/quiz ../.venv/bin/python -m pytest -ra -q -p no:cacheprovider
```

最终本地结果：**190 passed、0 failed、0 skipped**（31.48秒），另有一条依赖弃用提示。Ruff关键错误检查、Python compileall、两份JavaScript语法检查和git diff --check均通过。GitHub CI结果另在PR正文核对。
