## 续审与独立性

逐题呈现题干、答案/rubric、教材名称/OCR位置/摘录、转录风格等级、AI分析及不确定性、OCR/科学风险、自动重复提示及人工历史。自动重复提示不是人工结论。按两科学科/题型分别统计候选、人工通过及正式合格配额。

意见/核对项以账号隔离、追加版本自动保存；跨设备冲突先比较，禁止覆盖。浏览器IndexedDB用非导出AES-GCM密钥缓冲未同步意见，不保存教材正文/账号密码/令牌。它仍可能被同源脚本或已解锁设备读取，需设备锁；清理网站数据会丢失未同步草稿，须先确认服务器保存。没有缓存整站，完全离线不能重开未加载题目；已打开页面可缓冲，联网再同步。

服务器保存最后题目/筛选，支持上一题/下一题及刷新恢复。本人声明不自动恢复。暂存不是签署，真实账号主动通过/修改/退回仍须实质依据；绑定时间、版本、账号。候选通过不批准教材科学性、不发布题目；教材文本/科学/风险、可信映射、适用风格、答案/rubric及最终门禁仍分别满足。
